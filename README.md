# SOUL

SOUL is being rebuilt from first principles as a general-purpose agentic architecture for turning an intended outcome into a controlled, verifiable working system.

The repository has two deliberately separate concerns:

- `development/` — the operating system used to design, review, verify, and evolve SOUL itself.
- `system/` — the product that will eventually constitute the reusable SOUL system.

The repository is the authoritative source of project state. Chat history, model memory, and verbal summaries are supporting context only.

The first work package is the establishment of the SOUL Development Operating System before product architecture work begins.
