# Work Packages

Substantial SOUL development work is represented as a Work Package (WP).

Naming convention: `WP-XXX-SHORT-TITLE.md`.

A WP defines the bounded objective, scope/non-scope, required readings, dependencies, outputs, acceptance criteria, verification requirements, evidence obligations, risks and handoff. It may span multiple sessions, but each session should have one primary responsibility.

Use `WP_TEMPLATE.md`.

Current package: `WP-000-DEVELOPMENT-OS.md`.
