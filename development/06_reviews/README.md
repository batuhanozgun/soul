# Review Workspace

Independent verification and adversarial review artefacts live here.

A review is bound to the exact artefact or commit it inspected. A material later change makes the previous review stale for the changed properties.

- Use `VERIFICATION_TEMPLATE.md` for specification/claim verification.
- Use `ADVERSARIAL_REVIEW_TEMPLATE.md` for failure-seeking review.

Review sessions do not silently repair the work they are judging. Repairs return to a builder session and are then re-verified.
