# Architecture Workspace

This directory will contain SOUL's capability architecture and later its target architecture, core models, state model, runtime model, evidence/provenance model, and extension model.

Architecture work does not begin merely because this directory exists. The development operating system in Phase 0 must first be independently verified and accepted so that architecture decisions are produced under a stable source-of-truth, decision, work-package, and verification process.

The existing KEEL repository is evidence and prior art. It is not the default schema for SOUL. Useful mechanisms may be retained only after they are mapped to a required capability or architectural property in the new design.
