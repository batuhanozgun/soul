# Architecture Decisions

Accepted and proposed Architecture Decision Records (ADRs) live in this directory.

Use `development/01_governance/ADR_TEMPLATE.md`.

Naming convention: `ADR-XXXX-short-title.md`.

An ADR is required when a choice changes foundation, cross-cutting architecture, authority, state semantics, evidence/provenance, verification, runtime control, extensibility, or another property defined as architectural in `DECISION_POLICY.md`.

Research and evidence stay in `development/05_evidence/`; they may be linked from an ADR but are not copied here as if they were decisions.
