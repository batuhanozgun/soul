# Foundation

These files define the highest-authority project intent and constraints:

- `VISION.md` — why SOUL exists and the target class of system.
- `DEFINITION.md` — what SOUL is, is not, receives, produces, and how completion is understood.
- `SUCCESS_CRITERIA.md` — properties a credible v1 must demonstrate.
- `NON_NEGOTIABLES.md` — architectural properties that cannot be silently traded away.

Foundation changes require the highest decision discipline defined in `DECISION_POLICY.md` and human-owner approval after independent review.
