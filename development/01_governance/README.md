# Governance

This directory defines how SOUL development work is controlled before SOUL can automate those controls itself.

Canonical policies:

- `SOURCE_OF_TRUTH.md`
- `WORKING_PROTOCOL.md`
- `REASONING_POLICY.md`
- `ROLE_MODEL.md`
- `DECISION_POLICY.md`
- `VERIFICATION_POLICY.md`
- `CHANGE_POLICY.md`

`REASONING_POLICY.md` governs observable reasoning discipline for development sessions. It is loaded through the single `development/03_plan/COLD_START.md` sequence and does not replace active-WP authority, verification independence, or repository state.

Templates in this directory are procedural aids. They do not override the policies they implement.
