# SOUL System

This directory is reserved for the reusable SOUL product.

It must eventually be possible to move `system/` to a separate repository and operate the product without depending on development chat history, temporary research notes, review transcripts, or other scaffolding that belongs to `development/`.

No runtime implementation is created in Phase 0. Product architecture and technology choices are intentionally absent until the development operating system is verified and the subsequent definition/capability phases have established what the system must do.

Development artefacts may influence the product only through accepted architecture decisions and traced implementation work. They are not copied into the product merely because they exist.
